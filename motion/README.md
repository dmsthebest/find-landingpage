# FIND Motion V2

Nova versão do motion vertical (1080×1920) do FIND.

## Rodar studio

```bash
cd motion
npm install
npm run studio
```

## Renderizar

```bash
cd motion
npm run render
```

O MP4 sai em `motion/out/find-demo-v2.mp4`.
Depois copie para `public/find-demo.mp4` (o vídeo antigo fica em `public/find-demo-v1.mp4`).
